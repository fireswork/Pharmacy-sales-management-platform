# 药店销售管理系统

这是一个现代化的药店销售管理系统，用于管理药品库存、销售、采购、会员和员工等。系统采用前后端分离架构，前端使用 Vue 3 + Ant Design Vue，后端使用 Spring Boot。

## 功能特点

- **多门店管理**：支持多门店数据管理，可以在不同门店之间切换
- **药品管理**：药品信息维护、分类管理、价格调整
- **库存管理**：实时库存监控、库存预警、库存盘点
- **采购管理**：采购计划制定、采购订单管理、供应商管理
- **销售管理**：POS销售、销售记录查询、销售统计分析
- **会员管理**：会员信息管理、积分管理、会员营销
- **员工管理**：员工信息管理、权限分配、绩效考核
- **财务管理**：收支记录、财务报表、利润分析
- **系统设置**：用户管理、角色权限、系统参数配置

## 系统架构

### 前端技术栈

- Vue 3：JavaScript 框架
- Vite：构建工具
- Ant Design Vue：UI 组件库
- Vue Router：路由管理
- Axios：HTTP 客户端

### 后端技术栈

- Spring Boot：应用框架
- Spring Data JPA：数据访问
- Spring Security：安全框架
- MySQL：关系型数据库
- Maven：项目管理工具

## 安装指南

### 环境要求

- Node.js 16+
- JDK 11+
- Maven 3.6+
- MySQL 8.0+

### 后端安装

1. 克隆仓库
bash
git clone https://github.com/yourusername/pharmacy-management.git
cd pharmacy-management


2. 配置数据库

创建 MySQL 数据库，并在 `server/src/main/resources/application.properties` 中配置数据库连接：

properties
spring.datasource.url=jdbc:mysql://localhost:3306/pharmacy_db?useSSL=false&serverTimezone=UTC
spring.datasource.username=your_username
spring.datasource.password=your_password


3. 构建并运行后端
bash
cd server
mvn clean install
mvn spring-boot:run


后端服务将在 `http://localhost:8081` 上运行。

### 前端安装

使用 pnpm 代替 npm (推荐)
本项目也支持使用 pnpm 作为包管理工具，它比 npm 更快、更节省磁盘空间。
安装 pnpm
bash
npm install -g pnpm


1. 安装依赖
bash
cd front-end
pnpm install

2. 配置环境变量

创建 `.env.local` 文件，配置 API 地址：
VITE_API_BASE_URL=http://localhost:8080/api


3. 运行开发服务器
bash
npm run dev


前端服务将在 `http://localhost:5173` 上运行。

4. 构建生产版本
bash
npm run build


构建后的文件将在 `dist` 目录中。

## 使用指南

### 登录系统

1. 访问系统登录页面
2. 输入用户名和密码（默认管理员账号：admin/admin123）
3. 点击"登录"按钮进入系统

### 门店切换

1. 在顶部导航栏中找到门店选择下拉框
2. 选择要管理的门店
3. 系统会自动切换到所选门店的数据视图

### 药品管理

#### 药品列表

1. 在左侧菜单中点击"药品列表"
2. 可以查看所有药品信息，包括名称、价格、库存等
3. 使用搜索框可以按名称或编码搜索药品
4. 点击药品卡片可以查看详细信息
5. 点击"加入购物车"可以将药品添加到购物车

#### 药品管理

1. 在左侧菜单中点击"药品管理"
2. 可以添加、编辑、删除药品信息
3. 可以设置药品分类、价格、是否处方药等信息

### 库存管理

1. 在左侧菜单中点击"库存查询"
2. 可以查看当前门店的库存情况
3. 系统会自动标记库存不足的药品
4. 可以进行库存调整、盘点等操作

### 采购管理

1. 在左侧菜单中点击"采购管理"
2. 可以创建采购计划、采购订单
3. 可以跟踪采购订单状态
4. 可以管理供应商信息

### 销售管理

1. 在左侧菜单中点击"销售开单"
2. 可以进行 POS 销售操作
3. 可以查询销售记录、打印小票
4. 可以查看销售统计报表

### 会员管理

1. 在左侧菜单中点击"会员管理"
2. 可以添加、编辑、删除会员信息
3. 可以查看会员购买历史、积分情况
4. 可以进行会员营销活动设置

### 员工管理

1. 在左侧菜单中点击"员工管理"
2. 可以添加、编辑、删除员工信息
3. 可以设置员工权限、岗位
4. 可以查看员工绩效数据

## 常见问题

### 登录失败

- 检查用户名和密码是否正确
- 确认后端服务是否正常运行
- 检查网络连接是否正常

### 数据不显示

- 确认是否选择了正确的门店
- 检查后端 API 是否返回正确的数据
- 查看浏览器控制台是否有错误信息

### 系统运行缓慢

- 检查数据库性能
- 优化查询语句
- 考虑增加服务器资源
